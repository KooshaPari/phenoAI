# Specifications

## Acceptance Criteria

- Add the sladge badge near the README badge header.
- Do not modify automation runtime behavior or branding assets.
- Preserve canonical checkout changes by working only in the isolated worktree.
- Record the work in session docs.

## Out of Scope

- Changing desktop, mobile, or sandbox automation traits.
- Changing Sidekick event-bus integration.
- Reconciling the existing brand/logo work.
- Merging the prepared badge commit into the dirty canonical checkout.
